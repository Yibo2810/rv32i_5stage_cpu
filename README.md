# RV32I 5-Stage CPU

This repository contains a learning-oriented RV32I CPU project.

Planned milestones:

1. Define the supported RV32I instruction subset.
2. Implement and verify a single-cycle core.
3. Refactor the design into a classic 5-stage pipeline.
4. Add hazard detection, stalling, flushing, and forwarding.
5. Build assembly tests and automated simulation checks.
