# Project Plan

## Goals

- Build a minimal RV32I single-cycle CPU.
- Extend the design to a 5-stage pipeline.
- Verify correctness with focused assembly programs and testbenches.

## Milestones

1. ISA subset and memory model.
2. Single-cycle datapath and control.
3. Pipeline stage partitioning.
4. Hazard and forwarding logic.
5. Regression tests and result checking.
